# 🎓 DOM Lab — 15 Atividades de JavaScript

Projeto prático com **15 atividades de manipulação do DOM** em JavaScript puro, divididas em três níveis de dificuldade (**Fácil**, **Médio** e **Difícil**). Cada atividade resolve um problema real do dia a dia de quem desenvolve para web — do clássico "Olá, mundo" até um mini sistema acadêmico com cadastro, média, situação do aluno, pesquisa e contadores em tempo real.

---

## 🖼️ Preview

Interface com **tema dark moderno**, cards interativos, feedback visual nos inputs e botões, tabelas estilizadas e layout responsivo.

---

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura semântica
- **CSS3** — tema dark, variáveis CSS, grid, flexbox e responsividade
- **JavaScript (Vanilla)** — manipulação do DOM, eventos e lógica

---

## 📚 Conceitos praticados

- `document.querySelector()` e `querySelectorAll()`
- `addEventListener()` (click, input)
- `textContent`, `value`, `style`
- `createElement()` e `appendChild()`
- `dataset` (atributos `data-*`)
- Arrays de objetos e `forEach()`
- `filter()` e `includes()` para pesquisa
- `splice()` e `indexOf()` para exclusão
- `if / else if / else` para regras de negócio
- Atualização dinâmica da interface a partir de dados

## 📋 Lista das atividades

### 🟢 Nível Fácil

| # | Atividade | Descrição |
|---|-----------|-----------|
| 01 | Saudação | Lê o nome digitado e exibe uma mensagem personalizada |
| 02 | Alterando o título | Troca o texto e a cor de um `<h1>` ao clicar |
| 03 | Contador de cliques | Incrementa um contador a cada clique |
| 04 | Alterando uma mensagem | Muda o status de atendimento e o estilo |
| 05 | Calculadora simples | Calcula o total de um produto (quantidade × preço) |

### 🟡 Nível Médio

| # | Atividade | Descrição |
|---|-----------|-----------|
| 06 | Sistema de notas | Calcula a média de 3 notas e informa Aprovado/Reprovado |
| 07 | Validação de formulário | Verifica se os campos estão preenchidos |
| 08 | Sistema de estoque | Confere se há quantidade suficiente em estoque |
| 09 | Lista de tarefas | Adiciona tarefas dinamicamente em uma lista |
| 10 | Calculadora de desconto | Calcula valor do desconto e preço final |

### 🔴 Nível Difícil

| # | Atividade | Descrição |
|---|-----------|-----------|
| 11 | Sistema de login | Valida usuário e senha, oculta o formulário e mostra área logada |
| 12 | Carrinho de compras | Adiciona/remove produtos, calcula quantidade e total |
| 13 | Cadastro de alunos | Cadastra alunos em uma tabela com opção de excluir |
| 14 | Dashboard de vendas | Registra vendas, calcula faturamento e permite pesquisar |
| 15 | Mini sistema acadêmico | Cadastro completo com média, situação, pesquisa e contadores |
